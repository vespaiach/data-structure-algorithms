# Data Structures and Algorithms, Pattern by Pattern

Code for the course at https://stayon.online/courses/data-structures-and-algorithms/

There is one folder per module. Each folder holds the module's examples and benchmarks, plus:

- `exercises/`: stubs to fill in, with tests
- `solutions/`: worked answers to the same tests

You need Node.js 26 or newer, which runs TypeScript files directly. There are no packages to install.

```bash
cd module-02
node --test "exercises/*.test.ts"
```
